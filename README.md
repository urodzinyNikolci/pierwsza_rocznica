# Nasza pierwsza rocznica ❤️

Strona przygotowana do publikacji przez **GitHub Pages**. Działa na komputerach i telefonach, nie wymaga instalowania żadnych bibliotek ani procesu budowania.

## Pliki
- `index.html` — treść strony i list
- `style.css` — wygląd, responsywność i animacje
- `script.js` — otwieranie koperty, licznik czasu związku i pasek postępu czytania

## Publikacja na GitHub Pages
1. Utwórz nowe repozytorium na GitHubie, np. `nasza-rocznica`.
2. Wgraj do niego wszystkie trzy pliki (`index.html`, `style.css`, `script.js`) bezpośrednio do głównego katalogu.
3. Wejdź w **Settings → Pages**.
4. W sekcji **Build and deployment** wybierz **Deploy from a branch**.
5. Wybierz branch `main` oraz folder `/ (root)`, następnie kliknij **Save**.
6. Po chwili strona będzie dostępna pod adresem `https://TWOJ_LOGIN.github.io/nazwa-repozytorium/`.

## Ważne
- Nie zmieniaj nazw plików ani ich wzajemnego położenia.
- Czcionki pobierane są z Google Fonts; jeśli telefon nie ma internetu, strona użyje czcionek zastępczych.
- Treść listu została przeniesiona z przesłanego pliku DOCX bez redagowania.
